# quiz-me — REFERENCE

## 문항 유형

| 유형 | 목적 | 예시 stem |
|------|------|-----------|
| **범위** | 이번 작업 in/out | 「CWEB-1491에서 건드리지 않는 케이스는?」 |
| **구분** | 비슷한 케이스 분리 | 「US→MX와 MX 창고→MX 차이는?」 |
| **표기** | 화면 한글 라벨 | 「US→DE Avalara crossborder 세금 행 이름은?」 |
| **노출** | 행/문구 show-hide | 「MX 창고 국내 장바구니에서 세금 별do는?」 |
| **함정** | FE 분기 착각 | 「배송국=MX이면 항상 세금 및 처리 비용인가?」 |
| **순서** | 금액 행 순서 | 「WPQ #14 환불 행 순서는?」 |
| **판정** | 코드/플래그 | 「MX 국내 배송 판정에 쓰는 플래그는?」 |

## 난이도

- **R1** — 정의·범위 (라운드 1)
- **R2** — 구분·표기 (라운드 1~2)
- **R3** — 함정·2단계 추론 (후반 라운드)

한 quiz-me에 R1 ≥2, R2 ≥4, R3 ≥2 권장.

## 선지 작성

- 4지 + 「잘 모르겠음」 허용.
- 그럴듯한 **인접 오답** 1개 필수 (예: MX 창고 국내 vs US→MX).
- 「전부 해당」 「해당 없음」 남용 금지.

## 채점

| 결과 | 기준 |
|------|------|
| ✅ | 핵심 개념·케이스 정확 |
| ⚠️ | 방향 맞으나 용어/예외 하나 누락 |
| ❌ | 잘못된 케이스·범위 혼동 |

## 금지 패턴

- Jira/ md에 없는 국가·플래그 **낚시** 선지.
- 한 라운드에 **5문항 초과** (인지 부하).
- 채점 없이 다음 라운드 **연속 출제**.

## quiz-me vs grill-me

| | quiz-me | grill-me |
|---|------|----------|
| 정답 선공개 | ❌ | ✅ 권장 답 먼저 |
| 목적 | 사용자 **이해도 검증** | **결정** 수렴 |
| 흐름 | 출제 → 답 → 채점 | 질문 → 권장 → 확정 |

## CWEB-1491 계열 must-know (2026-07-05 · Phase 2 기획 기준)

- **세금**: WEA Avalara **전역 통일** — US→MX **포함** (`purchaseAmount.tax`)
- **세금 및 처리 비용**: Passport **AS-IS만** — TO-BE **제거** (`mxtax`)
- **관세 및 처리 비용**: WEA crossborder + WEK 해외
- US→US: Vertex (→ 이후 Avalara)
- MX 창고→MX: AS-IS #10 세·관세 없음 / TO-BE Avalara **세금**·관세 없음
- crossborder 판정: WEA + 배송국 ≠ US; MX 국내는 `isMexicoWarehouse` / `!isOverseas`

티켓이 바뀌면 이 블록을 **복사하지 말고** Step 1에서 해당 티켓 md 기준으로 새로 만든다.
