# 감시 규칙 — 놓친 것 챙기기

시간이 지나면 조용히 썩는 것들이 있다. 사람은 매일 보는 것에 눈이 미끄러진다.
**이 섹션의 목적은 "내가 안 챙긴 게 뭔가"를 대신 세는 것이다.**

## 규칙

`poll.py` 가 결정론적으로 계산한다. 판단이 아니라 산수다.

| # | 규칙 | 조건 | 등급 |
|---|---|---|---|
| W1 | **배포일 경과** | `releases.md` prod 배포일 < 오늘 **AND** 티켓 미완료 | 🔴 |
| W2 | **배포일 임박** | 배포일 − 오늘 ≤ 3일 **AND** 티켓 미완료 | 🔴 |
| W3 | **QA 시작 경과** | QA 시작일 ≤ 오늘 **AND** status 가 아직 개발 단계 | 🔴 |
| W4 | **미처리 ⚠️ 방치** | 히스토리의 미처리 `⚠️` 가 3일 이상 | 🟡 (7일↑ 🔴) |
| W5 | **문의 무응답** | `## 문의·Blocked` 갱신 후 3일 경과, Jira 코멘트 증가 없음 | 🟡 |
| W6 | **blocked 장기화** | `blocked: true` 가 7일 이상 유지 | 🟡 |
| W7 | **티켓 정체** | Jira `updated` 이후 14일 경과 **AND** 미완료 | 🟡 |
| W8 | **배포대기 적체** | `Ready to Deploy` 가 30일 이상 유지 | 🟡 |

임계값은 `config.toml` 의 `[watch]` 에서 조정한다. 코드에 박지 마라.

## 실측 기준 (2026-09-04)

이 임계값으로 지금 걸리는 것:

- W8: **11건** (WPQ-15228 254일, 디자인QA 9건 128~129일)
- W7: WV2Q-53784 46일, CWEB-1549 22일, CWEB-1550 21일

W8 이 11건이나 되므로 **반드시 접어야 한다.** 안 접으면 브리핑이 매일 같은 11줄로 시작한다.

## 반복 억제 — 이게 핵심이다

254일짜리 티켓을 매일 11줄로 보여주면 3일 만에 안 읽게 된다. 그러면 감시가 없는 것만 못하다.

`_state.json` 의 `watch` 키에 **처음 걸린 날짜**를 기록한다.

```json
"watch": { "WPQ-15228": { "W8": "2026-09-04" }, "CWEB-1549": { "W7": "2026-09-04" } }
```

표시 규칙:

| 상황 | 표시 |
|---|---|
| **새로 걸린 것** | 개별 줄로 전부 표시 |
| **이미 걸려 있던 것** | 규칙별 **집계 한 줄**로 접음 |
| **월요일** | 접힌 것도 전부 펼침 (주 1회 직면) |
| 🔴 등급 | 접지 않는다. 매일 개별 표시 |

```
*🔴 놓치면 안 되는 것 (2)*
• [shop 3.2.0] 배포일 09-03 경과인데 <…|WPQ-17676> 외 26건이 아직 Ready to Deploy
• [shop 3.3.0] <…|CWEB-1547> 미처리 ⚠️ 3건이 8일째 — 기획서 v44 반영 안 됨

*🟡 굳어가는 것*
• 신규: <…|CWEB-1549> 22일째 "진행 중" 무변화
• 누적: 배포대기 30일 초과 11건 (최장 254일) · 정체 14일 초과 3건
  → <obsidian://…|2026-09-04.md> 에 전체 목록
```

해소되면 `watch` 에서 지운다. 다음에 다시 걸리면 "새로 걸린 것" 으로 뜬다.

## ⚠️ 해소 판정

히스토리 줄이 `⚠️` 로 시작하고 **줄 끝에 `→` 처리 표시가 없으면 미처리**다.

```markdown
- `09-02 15:07` ⚠️ **Confluence** … v12 → v13 → D-02로 반영     ← 해소됨
- `09-04 09:37` ⚠️ **Confluence** … v26 → v44                  ← 미처리
```

나이는 줄 앞의 `MM-DD` 로 센다. 연도가 없으므로 오늘 기준으로 가장 가까운 과거 연도를 쓴다.

## 문의 무응답 판정 (W5)

`## 문의·Blocked` 에 내용이 있고, 그 섹션이 마지막으로 바뀐 뒤 3일이 지났는데
해당 Jira 이슈의 코멘트 수가 그대로면 **답이 안 온 것**으로 본다.

코멘트 수는 `_state.json` 의 티켓 엔트리에 `comments` 로 보관한다.
**Jira 에 코멘트를 달지 마라.** 읽기만 한다.

## 하지 말 것

- 규칙에 안 걸리는 걸 "느낌상 걱정된다"고 넣지 마라. 감시는 산수다
